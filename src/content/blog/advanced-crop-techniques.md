## Introduction

Cropping is essential for focusing on the subject and removing unwanted edges. In this guide, we explore advanced techniques using our Crop Tool, including custom aspect ratios, grid overlays, and keyboard shortcuts.

## Custom Aspect Ratios

- Use the **"Custom"** preset to enter any width:height ratio.
- Save presets for future projects.

## Grid Overlays

Enable grid lines to align subjects using the **"Overlay"** toggle.

## Keyboard Shortcuts

- **C**: Activate Crop mode.
- **R**: Reset crop area.
- **Enter**: Apply crop.

## Conclusion

Mastering these features lets you produce professional‑grade images quickly.

*Happy cropping!*
